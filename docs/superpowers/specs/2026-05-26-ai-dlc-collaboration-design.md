# AI DLC 협업 규칙 설계

**날짜**: 2026-05-26
**범위**: CLAUDE.md에 AI 협업 규칙 섹션 추가
**팀 규모**: 2인

---

## 배경

plAIng은 2인 팀이 Claude Code를 활용해 SDD + TDD로 개발하는 프로젝트다. 팀원 각자가 AI를 사용하는 방식이 달라지거나, AI가 생성한 코드에 대한 책임 소재가 불명확해지는 상황을 예방하기 위해 AI 협업 규칙을 정의한다.

## 핵심 원칙

> **AI가 작성한 코드도 커밋한 사람의 코드다.**

AI 사용 방식 자체는 제한하지 않는다. 설계 초안을 AI에 맡기든, 코드만 시키든 개인 자유다. 단, 결과물에 대한 책임은 항상 커밋한 사람에게 있다.

## 접근 방식

**체크포인트 기반**: AI가 뭘 하든 관계없이, 다음 단계로 넘어가기 전 확인 지점 3개를 정의한다.

## 체크포인트 정의

### 체크포인트 1 — 커밋 전

> AI가 생성한 코드를 본인이 이해하고, 동의했는가?

- AI 코드를 그대로 커밋하는 것은 허용
- 내용을 이해하지 못한 채 커밋하는 것은 금지
- 이해되지 않는 부분은 AI에게 설명을 요청한 후 커밋

### 체크포인트 2 — PR 전

> AI가 제안한 구조 변경이나 설계 결정이 스펙에 반영됐는가?

- AI가 설계를 제안해서 따랐다면 `docs/specs/`에 반영 후 PR 생성
- SDD 원칙 동일 적용: AI 제안도 스펙 없으면 구현 없음

### 체크포인트 3 — CLAUDE.md 수정 전

> 팀원과 합의했는가?

- CLAUDE.md 단독 수정 금지 (두 사람의 AI 동작이 달라짐)
- 변경 시 팀원 동의 후 커밋
- 새 섹션 추가 또는 기존 규칙 삭제 등 큰 변경은 PR 필수

## CLAUDE.md 거버넌스

- 작업 시작 전 항상 `git pull` — CLAUDE.md 최신 상태 보장
- 이 규칙은 루트 `CLAUDE.md`, `backend/CLAUDE.md`, `frontend/CLAUDE.md` 모두에 적용

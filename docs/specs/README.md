# Specs

이 디렉토리는 plAIng 프로젝트의 도메인 스펙 문서를 관리합니다.

## 파일 네이밍

```
docs/specs/{domain}.md
```

예시: `user.md`, `payment.md`, `notification.md`

## 스펙 작성 순서

1. 새 도메인 또는 기능 개발 시 이 디렉토리에 스펙 파일 먼저 작성
2. `docs(domain-{name}): {domain} 도메인 스펙 작성` 으로 커밋
3. 팀원 리뷰 후 구현 시작

## 스펙 파일 템플릿

```markdown
# {Domain} 도메인

## 개요

> 이 도메인이 해결하는 문제와 핵심 책임을 1-2문장으로 요약

## API

### GET /api/{domain}/{endpoint}

**요청**
| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| id | Long | O | 식별자 |

**응답**
```json
{
  "success": true,
  "data": {}
}
```

**비즈니스 규칙**
- 규칙 1
- 규칙 2

## 데이터 모델

| 필드 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | Long | PK | 식별자 |

## 예외

| 코드 | 상황 |
|------|------|
| NOT_FOUND | 리소스 없음 |
```
